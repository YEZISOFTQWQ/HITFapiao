# hitcwc材料验收单生成

本程序读取目录中的 PDF 发票，提取发票号、日期、购买方、供应商和商品明细，然后生成材料验收单。材料验收单风格为cwc.hit（本部），符合本部计财处要求
Release[https://github.com/YEZISOFTQWQ/HITFapiao/releases]

---

- 支持新版电子发票和深圳增值税电子普通发票。
- 从文件名提取材料关键词，并在解析后弹出逐条确认窗口；可按 Enter 快速确认下一条，或按 Ctrl+O 打开发票对照。
- 按含税金额填写材料名称、单位、数量、含税单价、含税金额和供应商。
- 校验每张发票的明细含税合计、价税合计和文件名中的金额。
- 验收日期始终读取生成时的系统日期。
- 非标准发票格式、购买方名称错误或纳税人识别号错误时，对应验收单明细标红并在界面提示。购买方标准值为“哈尔滨工业大学 / 12100000400000456B”。
- 同一供应商的发票累计金额超过 1000 元时，供应商单元格标黄并在界面提示。
- 连续相同的供应商会在供应商列合并显示。
- 生成验收单时，会把每张原发票归档为 `1.材料名称[金额].pdf`；同一张多明细发票只归档一次，材料名称使用人工确认后的结果。
- 自动生成 `发票打印汇总.pdf`：A4 竖版，每页两张发票，上下排列并保持原始比例。
- 可从已有归档文件夹重新生成打印汇总。按文件名前缀的真实整数大小排序，允许缺号和同号；命名不符合 `序号.材料名称[金额].pdf` 的 PDF 会排除并在界面提示。

## 运行

电脑需安装 Microsoft Excel。首次运行：

```powershell
.\setup.ps1
.\run.bat
```

`setup.ps1` 会在项目目录创建 `.venv` 虚拟环境并检查依赖。图形界面默认指向本项目的 `demo` 和 `模板.xls`。

## 命令行

```powershell
.\.venv\Scripts\python.exe -m invoice_acceptance.cli `
  --invoice-dir .\demo `
  --template .\模板.xls `
  --output .\输出\材料验收单.xls
```

可选参数包括 `--unit-name` 和 `--expense-card`。使用 `--parse-only` 可只查看 JSON 解析结果。命令行使用文件名关键词作为材料名称；需要逐条人工确认时请使用图形界面。

只从已经人工整理过的发票归档重新生成打印汇总：

```powershell
.\.venv\Scripts\python.exe -m invoice_acceptance.cli `
  --combine-existing .\输出\材料验收单_发票
```

此模式直接读取文件夹中的标准命名 PDF。序号会按数值排序，例如 `2` 位于 `10` 之前；序号不要求连续，相同序号的文件都会处理。

## 填写

- 金额采用发票含税金额，验收单合计应与全部发票的价税合计一致。
- 含税单价按“含税金额 ÷ 数量”计算，避免不含税单价与验收单金额口径不一致。
- 解析失败时默认停止生成，防止遗漏发票；处理前应在明细表中核对结果。
